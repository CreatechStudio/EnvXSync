# EnvXSync Frontend

## Development
1. Install dependencies
```shell
pnpm install
```
2. Start the development server
```shell
pnpm dev
```

## Technologies Used
- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [HeroUI](https://www.heroui.com/)
